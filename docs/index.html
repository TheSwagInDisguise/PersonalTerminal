Screens

The same app, wherever the window lands.

Every screen is rendered headless in CI at three window shapes — a phone, an open fold, a half-folded tabletop — so a layout regression never ships.

Fold 5

Built for the fold.

Android 16 hands resize events to apps targeting SDK 36 — so the layout measures its own hinge and adapts to all three postures.

  • 344dpCover status line drops indices and brackets so every tab fits one line.
  • 690dpOpen side rail plus split panes, divider centred on the physical fold.
  • flexTabletop pomodoro above the hinge, controls below, safe around the taskbar.
  • stateSurvives folding mid-edit no longer resets the screen you were on.
