✓ 38 goldens ● w344 · w690 · w829 ✓ CI gated

Every screen is rendered headless with Robolectric on the CI runner and compared pixel-by-pixel against the committed golden images — a phone, an open fold, and a half-folded tabletop, each pinned to a fixed clock and seeded demo profile.

Change a layout on purpose? Re-bake the goldens with one command — or dispatch the render-goldens workflow and let the runner do it.
