Screens

The same app, wherever the window lands.

Every screen is rendered headless in CI at three window shapes — a phone, an open fold, a half-folded tabletop — so a layout regression never ships.

flex mode ↷

Built for the fold.

One UI 8 hands Android 16 apps the real window — so PersonalTerminal measures its own hinge and adapts to all three postures of a Galaxy Fold 5:

  • Cover (344dp) — the five-tab status line drops indices and brackets so every tab fits on one line.
  • Open (690dp) — side rail plus split panes, divider centred on the physical fold.
  • Tabletop / Flex — pomodoro countdown above the hinge, controls below it, safe around the taskbar.
  • State survives — folding mid-edit no longer resets the screen you were on.
